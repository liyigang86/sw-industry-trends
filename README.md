# 申万一级行业趋势

一个无需构建的本地 Web 页面，用日线观察 31 个申万一级行业的绝对收益、相对沪深 300 强弱与均线趋势，并支持在日线、周线、月线之间切换。热力图提供最近 12 周和最近 20 个交易日两种视图；全行业叠加图使用 31 种颜色区分行业，并同时显示上证指数、沪深 300、中证 1000、中证 2000 四条大盘基准。

页面支持直接从公司名称或股票代码开始查询，自动定位其申万一级、二级行业，并展示短线交易、行业轮动、中长期基本面和概念关联。顶部的“行业资金温度”面板展示 31 个一级行业的主力净流入、主力净流入占比、行业量比、当日涨跌和成交额。

页面内容分为“行业趋势”“乖离率”“资金温度”“概念热点”和“公司研究”五个标签：行业标签集中展示趋势和热力图，行业轮动可在申万一级、二级行业之间切换，并在名称旁显示价格趋势与资金历史合成的持续性评分；一级使用自身板块资金历史，二级使用所属一级行业资金作为8%的辅助项。乖离率标签按日线、周线或月线显示 31 个行业相对 MA20/60/120/250（周、月线自动采用对应周期）的偏离程度、历史分位与排行，不生成买卖信号；资金标签展示 31 个一级行业的主力净流入、占比、量比和成交额，并可按一级行业选择申万二级行业，汇总其成分股资金流并查看具体股票；概念热点标签集中展示热点概念、概念轮动和概念反查股票；公司标签集中展示公司定位、基本面、估值和该公司自身的概念画像。标签选择会保存在浏览器中。

## 直接双击打开

压缩包内的 `industry-dashboard.html` 是单文件离线版，不需要 Python、启动服务或安装依赖，直接双击即可打开。行业趋势、日/周/月切换、热力图、31 个一级行业的二级数据和随包内置的公司详情均可使用。

单文件版受浏览器安全限制，无法实时更新，也不能查询未随包内置详细资料的公司。需要“双击打开并自动更新”时，双击 `open-auto-update.bat`：它会启动本地服务并自动打开浏览器，打开页面时会检查最新行情。

## 打开页面

需要 Python 3.9 或更高版本，不需要安装任何第三方 Python 包。

Windows 可以直接双击 `start.bat`；macOS/Linux 运行：

```bash
chmod +x start.sh
./start.sh
```

`start.sh` 会自动检查 Python 3.9+；未安装时会根据系统尝试使用
`apt-get`、`dnf`、`yum`、`pacman`、`zypper`、`apk` 或 Homebrew 安装。安装系统包时
可能需要输入当前用户的 `sudo` 密码。

Windows 的 `start.bat` 会自动检查并准备 Python：已安装时直接启动；未安装时优先通过
`winget` 安装 Python 3.12，`winget` 不可用时会从 Python 官网下载官方安装包并按当前
用户静默安装，不需要管理员权限，也不需要 `pip install` 第三方包。

也可以手动启动：

```powershell
python .\server.py
```

然后访问 `http://127.0.0.1:8765/`。

页面会先显示随包附带的本地数据，并立即请求 `/api/data` 检查申万最新日线。如果发现新交易日，会自动刷新页面；如果上游尚未发布，则显示“上游尚未更新”和实际截止日期。5 分钟内重复打开会复用检查结果，避免反复请求。网络不可用时仍可使用包内缓存查看。

交易时段内，资金温度面板每 60 秒检查一次 `/api/industry-flow`。服务端对资金快照做 30 秒缓存，数据通常有 1～5 分钟延迟；非交易时段不会自动请求，但仍可手动刷新。这里的“主力净流入”是按成交单大小分类估算，不等同于基金申购赎回或真实新增资金。

部署到其他机器时不需要安装任何 Codex 技能。默认会由部署机直接访问申万宏源、东方财富和乐咕乐股；请确保该机器能够访问这些 HTTPS 站点。当前开发机使用 SSH 代理取数时，可在启动前设置：

```powershell
$env:SW_FETCH_HOST = 'yz'
python .\server.py
```

`SW_FETCH_HOST` 也可以填其他已配置好公钥登录的 SSH 主机。未设置时执行直接联网模式。

选择一级行业后，二级行业下拉框会列出对应子行业。二级行业历史数据按一级行业分组、按需从本机 `/api/level2` 服务加载并缓存在 `level2_cache/`，因此不会在首次打开页面时一次性下载全部 124 个二级行业。

选中具体二级行业后，相对趋势图会保留全部同级曲线并突出所选行业，同时在页面下方加载该二级行业的成分公司列表。行业成员名单与实时行情分开处理：成员来自乐咕乐股，价格、当日/5日涨跌、市值和PE(TTM)通过东方财富批量行情覆盖，并缓存在 `companies_cache/`。打开二级行业时会强制刷新，交易时段超过两分钟也会自动更新。

点击公司名称后，页面会展开三段式投资画像：短线交易（5/20 日收益、均线偏离、量比）、行业轮动（相对所选二级行业的 5/20/60 日强弱）和中长期基本面筛选（营收增速、归母净利润增速、ROE、毛利率、资产负债率、净利润现金含量及行业排名）。工商资料和公司简介收进折叠区。资料按公司代码从 `/api/company-info` 获取，并缓存在 `company_info_cache/`；打开公司时会强制刷新行情，服务端同时校验 `market.asOf`，交易时段缓存超过两分钟也会自动更新。

公司卡片中的一级、二级行业可以直接点击，返回对应行业走势。概念标签按“核心业务相关、业务延伸、弱题材关联”三档展示，点击任意概念可查看原始入选依据、依据日期、分类依据和旧依据提示。分类为规则初筛，不代表概念对应的收入占比。

“资金温度”页顶部新增全市场脉搏：按沪深京 A 股统计剔除 ST 后的涨跌分布、涨跌停数量和涨跌家数；全天量能使用上证指数、深证成指和北证50成交额合计，并按最近 20 个交易日同一时刻的五分钟成交完成度中位数进行盘中估算，同时给出历史分位区间和相对昨日量能变化。31 个一级行业也按各自板块的分钟成交历史分别估算预计全天成交额和昨日增减，行业卡片会直接显示“当前成交、预计全天、较昨日量能”。

“概念热点”标签展示近期热点概念排行，热点综合由基础热度60%、涨停事件25%和5分钟资金速度15%组成：基础热度按5日涨幅、60日趋势、当日涨幅、当日主力净流入占比、上涨家数占比、量比和成交额计算；资金速度取累计主力净流入最近5分钟变化并按候选概念横截面分位计算；涨停事件通过涨停股的正式概念映射统计概念内涨停数、连板数、最高板和炸板质量。“盘中概念资金流”读取题材概念的1分钟累计主力净流入，可切换累计资金和资金速度视图，单位为亿元及亿元/分钟，图例可切换显示。“事件主题层”读取最近5个交易日的涨停原因，把“羊字辈、AI影视、人形机器人”等临时市场叙事拆成动态标签，并按涨停股覆盖、连板高度、封单、换手和历史复现自动聚合；每张卡片可以展开查看该事件涉及的全部涨停股，它用于补充正式概念板块无法覆盖的事件主题，不依赖固定名单。“概念轮动与持续性”从近期高热、高成交、60日趋势和短线热度较强的题材中动态选样，展示近 12 周或近 20 日热力图，并在概念名称旁直接显示趋势、资金、广度、动量和量能合成的持续性证据分。概念反查股票使用严格候选模型计算“龙头候选、中军候选、跟风/分歧”：区分主板、创业板、科创板涨停阈值，加入首次封板时间、连板高度、炸板次数、近5日板块内领导稳定性和上涨共振，再结合涨幅、5日动量、市值、成交与资金。对于大概念只为初筛候选拉取历史行情，角色随行情动态变化，不是官方固定标签。点击热点或概念名称可以继续反查相关股票。系统先匹配东方财富概念板块；没有完全同名板块时，会对“物理AI / 具身智能”等常见词做相近概念映射，并在页面明确标注。结果会合并多个概念板块的成分股、去重后按主力净流入排序；概念名单不代表公司实际收入占比。

公司页会显示三情景估值。银行使用 PB-ROE：以近三年公司 PB 分位与当前 42 家上市银行 PB 分位确定悲观、基准、乐观目标 PB，用归一化 ROE、分红率与可持续增长率预测未来一年每股净资产，再计算目标价和隐含股息率。其他行业默认使用“行业 PE/ PB 分位 + 成长情景”：近三年营收和利润增速确定基准增速及情景波动，公司自身估值分位与对应申万一级行业成分股估值分位确定目标倍数；周期、地产和非银金融优先使用 PB，利润为负或 PE 不适用时自动使用 PB。该结果仅用于估值对照，不构成目标价承诺。

## 更新数据

```powershell
python .\fetch_sw_trends.py
python .\fetch_industry_flow.py
python .\fetch_industry_fund_history.py
python .\fetch_concept_heat.py
python .\fetch_event_themes.py
python .\fetch_concept_hotspot.py
python .\fetch_concept_intraday_flow.py
python .\fetch_concept_rotation.py
python .\fetch_event_themes.py
```

脚本默认由当前机器直接访问公网，拉取申万宏源研究所的申万一级行业日线，以及东方财富的上证指数、沪深 300、中证 1000、中证 2000 日线，并生成页面直接读取的 `data.js`。脚本支持断点续传和接口重试。

只有在使用单独的 SSH 取数代理时才需要设置 `SW_FETCH_HOST`。没有该环境变量时，所有取数脚本都使用本机直接联网模式。

如需单独更新某个二级行业的成分公司：

```powershell
python .\fetch_industry_companies.py 801081
python .\fetch_company_info.py 688981.SH
```

成分公司分类及行情数据来自乐咕乐股；公司行情使用东方财富和腾讯证券交叉检查，财务指标使用东方财富和同花顺交叉检查。页面内可展开查看各项数据的两源数值和误差。

## 指标口径

- 区间收益：所选区间首尾周收盘点位变化。
- 相对沪深 300：以同一区间内沪深 300 的累计收益为基准计算超额收益。
- 趋势状态：结合收盘价、13 周均线、26 周均线及 13 周均线斜率判断。
- 趋势广度：收盘价位于 13 周均线上方的行业占比。
- 近期热力图：各行业最近 12 个周收益，红色为上涨、绿色为下跌。

页面仅用于市场观察，不构成投资建议。

## 发布包内容

- `index.html`、`app.js`、`styles.css`：页面程序和样式。
- `data.json`、`data.js`：最近一次生成的申万一级行业、二级行业和市场基准数据。
- `industry_flow_cache.json`：最近一次 31 个一级行业资金流与量比快照。
- `level2_cache/`、`companies_cache/`、`company_info_cache/`：按需预取的数据缓存。
- `company_directory.json`：A 股公司名称和代码索引。
- `server.py`、`fetch_*.py`：本地服务及自动更新脚本。
- `start.bat`、`start.sh`：Windows 和 macOS/Linux 启动入口。
- `open-auto-update.bat`：Windows 双击启动、自动打开浏览器并检查最新数据。
- `industry-dashboard.html`：无需服务的单文件离线版。
- `build_standalone.py`：重新生成单文件离线版。
